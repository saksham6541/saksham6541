## 🌟 What I'm Working On

### **Nagriksetu** 🏙️
*AI-powered hyperlocal civic issue resolution platform*

The big one. Connecting citizens, municipal officers, and field workers to fix potholes, streetlights, water issues — the real stuff that affects neighborhoods.

- Hyperlocal issue reporting & tracking
- AI-powered severity classification & routing
- Real-time resolution updates
- **Tech:** TypeScript, React, Node.js, AI integration

[Check it out →](https://github.com/saksham6541/nagriksetu)

### **Distributed File Upload System** 📤
*Building a chunked, resumable, scalable file upload backend*

Understanding how large-scale platforms handle uploads. Auth complete, chunking & distribution in progress.

- Express/TypeScript backend
- React/Vite frontend
- MongoDB for metadata
- Resume-able uploads with chunk verification

### **DSA Grind** 💪
*Practicing data structures & algorithms systematically*

Not for interviews (well, partly), but to understand efficiency at scale. You can't optimize what you don't understand.

[PDSA Repository →](https://github.com/saksham6541/PDSA)
